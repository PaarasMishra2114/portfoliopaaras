# Paaras Mishra Portfolio

Personal portfolio for Paaras Mishra, focused on AI/ML engineering, full-stack development, edge AI, and practical web systems.

## Highlights

- AI/ML and full-stack project showcase
- Experience in Generative AI, RLHF/SFT, and web development
- Interactive project notes and skills tabs
- Credential tabs for AWS Academy, Google badges, Claude, Oracle, and other certifications
- Profile image and downloadable resume
- Responsive layout with reduced-motion support

## Run Locally

This is a static HTML, CSS, and JavaScript site. From the project folder, run:

```powershell
python -m http.server 5500
```

Open [http://localhost:5500](http://localhost:5500) in a browser.

## Deploy With Vercel

1. Import `PaarasMishra2114/portfoliopaaras` at [vercel.com/new](https://vercel.com/new).
2. Select the repository and keep the default project settings.
3. Deploy. Vercel will publish the static site and provide a free `vercel.app` address.

Future changes pushed to the `main` branch will redeploy automatically when the Vercel project is connected to the repository.
